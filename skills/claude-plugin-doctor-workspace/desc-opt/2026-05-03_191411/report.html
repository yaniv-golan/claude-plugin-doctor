claude-plugin-doctor — Skill Description Optimization

Optimizing your skill's description. This page updates automatically as Claude tests different versions of your skill's description. Each row is an iteration — a new description attempt. The columns show test queries: green checkmarks mean the skill triggered correctly (or correctly didn't trigger), red crosses mean it got it wrong. The "Train" score shows performance on queries used to improve the description; the "Test" score shows performance on held-out queries the optimizer hasn't seen. When it's done, Claude will apply the best-performing description to your skill.

Original: Diagnose drift across the six cache layers of the Claude Code / Claude Desktop plugin system using the `cpd` CLI (`claude-plugin-doctor`). Use when a Claude plugin is still loading an old version after `claude plugin marketplace update` or `claude plugin update`, when those report `already at latest version` but it isn't, when a plugin author bumped `plugin.json#version` but Desktop's `Update available` badge stays silent, when an installed plugin's files are missing on disk, or when troubleshooting upstream Anthropic plugin-cache bugs (issues #46081, #13799, #19197, #15642, #35691, #48675). Runs `cpd --json` to pinpoint which cache layer is stale (marketplace clone, install snapshot, Cowork mirror, RPM copy, skills-plugin) and proposes the minimum-impact fix — refresh, version bump, `--force-fetch` bypass for the silent-cooldown bug, or registration cleanup — for the user to confirm before any destructive operation.
